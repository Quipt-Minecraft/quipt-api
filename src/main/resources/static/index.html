Quipt REST Endpoints

Preview key endpoints below or explore full schemas in our dedicated documentation portal.

POST /account/register
Register new studio account and dispatch verification token
GET /account/verify
Verify email address using cryptographic verification token
ANY /account/edit
Grant permissions (add_permission) or issue tokens (create_token)
GET /token/validate
Validate API tokens provided via Authorization header
POST /files/upload
Upload and sanitize files into managed sub-directories
GET /files/download/**
Stream and download stored server assets securely
